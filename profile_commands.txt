======================================================================
TRADING INTERFACE - COMPLETE COMMAND REFERENCE
======================================================================

📊 MARKET DATA COMMANDS:
  quote <symbol>
    Get real-time market quote (bid, ask, last, volume)
    Example: quote MNQ

  depth <symbol>
    Get market depth (order book) with bids and asks
    Example: depth MNQ

  history <symbol> [timeframe] [limit] [raw] [csv]
    Get historical price data (bars)
    Timeframes: 1s, 5s, 10s, 15s, 30s, 1m, 2m, 3m, 5m, 10m, 15m, 30m, 1h, 2h, 4h, 1d
    Examples: history MNQ 5m 100
              history MNQ 1m 50 raw    (tab-separated output)
              history MNQ 5m 100 csv (export to CSV file)

  chart [symbol] [timeframe] [limit]
    Open interactive chart window GUI
    Example: chart MNQ 5m 100

  contracts
    List all available trading contracts with details


💰 ACCOUNT & RISK COMMANDS:
  account_info
    Get detailed account information (balance, equity, margin, etc.)

  account_state
    Show real-time account state (balance, PnL, positions summary)

  compliance
    Check account compliance status (DLL, MLL, trailing drawdown)

  risk
    Show current risk metrics and limits

  drawdown (also: max_loss)
    Show max loss limit and drawdown information

  trades [start_date] [end_date]
    List trades with FIFO consolidation and statistics
    Example: trades 2025-12-01 2025-12-04

  accounts
    List all your trading accounts

  switch_account [account_id]
    Switch to a different account without restarting
    Example: switch_account 12694476

  metrics
    Show performance metrics and system stats (API calls, cache, memory, CPU)


📈 TRADING ORDER COMMANDS:
  trade <symbol> <side> <quantity>
    Place a market order
    Example: trade MNQ BUY 1

  limit <symbol> <side> <quantity> <price>
    Place a limit order at specified price
    Example: limit MNQ BUY 1 19500.50

  bracket <symbol> <side> <quantity> <stop_ticks> <profit_ticks>
    Place a bracket order with stop loss and take profit (in ticks)
    Example: bracket MNQ BUY 1 80 80

  native_bracket <symbol> <side> <quantity> <stop_price> <profit_price>
    Place a native TopStepX bracket order with linked stop/take profit
    Example: native_bracket MNQ BUY 1 19400.00 19600.00

  stop_bracket <symbol> <side> <quantity> <entry_price> <stop_price> <profit_price>
    Place a stop entry order with stop loss and take profit prices defined
    Example: stop_bracket MNQ BUY 1 25800.00 25750.00 25900.00

  stop_buy <symbol> <quantity> <stop_price>
    Place a stop buy order (triggers market buy when price reaches stop_price)
    Example: stop_buy MNQ 1 25900.00

  stop_sell <symbol> <quantity> <stop_price>
    Place a stop sell order (triggers market sell when price reaches stop_price)
    Example: stop_sell MNQ 1 25900.00

  stop <symbol> <side> <quantity> <price>
    Place a stop order (legacy command, use stop_buy/stop_sell)
    Example: stop MNQ BUY 1 19400.00

  trail <symbol> <side> <quantity> <trail_amount>
    Place a trailing stop order
    Example: trail MNQ BUY 1 25.00


📦 POSITION MANAGEMENT COMMANDS:
  positions
    Show all open positions with P&L, entry price, current price

  orders
    Show all open orders with status and details

  close <position_id> [quantity]
    Close a position (entire or partial)
    Example: close 425682864 1

  cancel <order_id>
    Cancel an order
    Example: cancel 12345

  modify <order_id> <new_quantity> [new_price]
    Modify an existing order
    Example: modify 12345 2 19500.00

  modify_stop <position_id> <new_stop_price>
    Modify the stop loss order attached to a position
    Example: modify_stop 425682864 25800.00

  modify_tp <position_id> <new_tp_price>
    Modify the take profit order attached to a position
    Example: modify_tp 425682864 26100.00

  flatten
    Close all positions and cancel all orders
    Requires confirmation by typing 'FLATTEN'


🔄 MONITORING & AUTOMATION COMMANDS:
  monitor
    Monitor position changes and automatically adjust bracket orders
    Use this after adding/subtracting contracts to existing positions

  bracket_monitor
    Monitor bracket positions and manage orders

  activate_monitor
    Manually activate monitoring for testing

  deactivate_monitor
    Manually deactivate monitoring

  check_fills
    Manually check for filled orders and send Discord notifications

  test_fills
    Test fill checking with detailed output

  auto_fills
    Enable automatic fill checking every 30 seconds

  stop_auto_fills
    Disable automatic fill checking

  clear_notifications
    Clear notification cache to re-check all orders


🎯 STRATEGY MANAGEMENT COMMANDS:
  strategies list (or: strategies)
    List all available strategies

  strategies status
    Show status of all strategies

  strategies start <name> [symbols]
    Start a specific strategy
    Example: strategies start overnight_range MNQ MES

  strategies stop <name>
    Stop a specific strategy
    Example: strategies stop overnight_range

  strategies start_all
    Start all enabled strategies

  strategies stop_all
    Stop all strategies

  strategy_start [symbols]
    Start overnight range breakout strategy (legacy command)

  strategy_stop
    Stop the overnight strategy (legacy command)

  strategy_status
    Show overnight strategy status and configuration (legacy command)

  strategy_test <symbol>
    Test strategy components (ATR, ranges, orders) (legacy command)

  strategy_execute [symbols]
    Manually trigger market open sequence for testing (legacy command)


⚙️  SYSTEM COMMANDS:
  help
    Show this help message

  quit (or: q)
    Exit trading interface

💡 TIPS:
   - Use ↑/↓ arrows to navigate command history
   - Use Tab key for command completion
   - All commands are case-insensitive
   - Symbol names are automatically converted to uppercase
   - Use 'raw' flag with history for fast tab-separated output
   - Use 'csv' flag with history to export data to CSV file
