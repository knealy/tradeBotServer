## ⚡ Quick Start Commands

### Open the Trading Bot
```bash
# Interactive CLI
python trading_bot.py

# Select account 1
1

# Trade!
> quote MNQ
> trade MNQ BUY 1
```

### Open the GUI
```bash
# From CLI
> master

# Or directly
python trading_bot.py --account_select=1 --command='master'
```

### Start a Strategy
```bash
> strategies start simple_candle --symbols=MNQ --timeframe=15s
```
