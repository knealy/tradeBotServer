# Opening Range Breakout (ORB) — same-day breakout strategy (R1 committed).
#
# Created 2026-06-09 to test ORB-style alpha that ``overnight_range`` could
# not measure cleanly (its ``track_overnight_range`` hard-codes a 1-minute
# history fetch with a 10-bar minimum — silently produces zero trades for
# windows < ~60 min when the backtest CSV is 5m).  See
# ``strategies/opening_range_breakout_strategy.py`` module docstring.
#
# ── R1 sweep results (2026-06-09 evening, MNQ-focused, 09:30 → 10:30
#    60-min window, long-only, skip Friday):
#       9m walk-forward:  RF 4.09  ret +151.94 %  DD 31.23 %  WR 56.25 %  n=80
#       6m walk-forward:  RF 3.66  ret +131.86 %  DD 33.24 %  WR 54.72 %  n=53
#       3m walk-forward:  RF 4.67  ret +142.24 %  DD 25.16 %  WR 56.67 %  n=30
#    ON 3m THIS BEATS overnight_range R24 (RF 2.20 / +39.67 % / DD 18 %)
#    BY 2.1× — the most recent quarter is where ORB has the clean edge.
#    Sweep artifacts: docs/perf/_opt_runs/orb_strategy_mnq_focused/
#
#    Mechanism: post-09:30 open shows a clean range-break trend bias in
#    current data; the long side of a 60-min ORB rides into the NY
#    morning trend.  Short side and 15/30-min ORBs lose money (range too
#    narrow → false breaks).  Friday is the worst-edge day (49 % WR /
#    average MFE drift) — skipped.  MGC ORB consistently loses (~–$45
#    avg loss per fold across windows) → MGC excluded from rotation.
#
# ── DD note: 25–33 % DD across all 3 windows is HIGH for a prop firm.
#    Run on a higher-balance account ($25k+) with position_size = 1 so
#    a single drawdown sequence stays inside the $1 000 daily-loss cap.
#    Consider lowering to position_size = 0 (disabled) on shared-cap
#    accounts.
