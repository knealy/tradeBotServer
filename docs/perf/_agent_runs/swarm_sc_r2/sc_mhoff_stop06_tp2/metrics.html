# Simple Candle / "2-bar distance break" momentum strategy.
#
# 2026-06-01 wiring complete (Round 2):
#   - Already routed through place_bracket_order (no execute() fix needed).
#   - Added cooldown (signal_cooldown_bars=6) + replay-aware position
#     guard. Without these, the 2-bar displacement test re-fired every
#     bar of an uptrend, stacking entries.
#   - Profit/stop multipliers exposed in TOML (were hardcoded 2.0/1.5);
#     tightened to 1.5/1.0 for shorter holds.
#
# Current 90d / 3-fold MNQ walk-forward (after wiring):
#   trades=164, avg_bars_held=190, ret=+2562%, maxDD=228% → POSITIVE
#   RETURN but maxDD>100% means a blown account.  Strategy edge is real
#   (P&L positive over the window) but the per-trade risk is too large;
#   needs:
#   - max_hold_bars exit (positions hold ~16 hours = overnight risk)
#   - tighter trend_filter.min_trend_score (currently 20, may need 30+)
#   - per-symbol parameter sweep
#
# Alpha thesis (this is the EXPLICIT alpha we are wiring in 2026-06):
#   Two consecutive bars closing OUTSIDE the prior bar's range (c1.close >
#   c0.high AND c2.close > c1.high, mirrored for shorts) is a low-noise
#   "displacement out of recent compression" pattern.  Trend filter
#   confirms the regime is directional (EMA8/EMA21 separation + ATR
#   expansion + same-direction candle streak), and the trade enters at a
#   small momentum offset above c2 with a 1.5-ATR target / 1.0-ATR stop.
#
# Why it differs from morning_range_reversion / overnight_range:
#   - Both range strategies key off a single multi-bar anchor (a 60-min
#     morning range, an overnight range). simple_candle keys off two
#     individual bars — much higher cadence, much shorter holds.
#   - Trend filter (EMA8/EMA21) is the regime gate, not a time-of-day
#     window. So it can fire anytime there is real displacement on the
#     configured timeframe.
#
# Backtest knobs are set so the strategy actually GENERATES trades when
# the recap harness drives it (timeframe = 5m matches the shipped CSVs;
# trend filter starts at score=20 to let signals through without going
# wide-open; in/out window is 24h since the strategy gates itself).
#
max_hold_bars = 0
stop_multiplier = 0.6
profit_multiplier = 2.0

# Enabled for backtest research as of Round 6 wiring.  Not yet a
